# 课堂课件的语义分页

用于新建、改写和重新渲染课件。以教师按页面顺序讲述时能完整结束一个主题为目标；页面留白可以接受，打断模块、交错讲述和失去比较关系不能接受。

## 先分类，再排版

| 内容关系 | 页面组织 | 容量不足时 |
|---|---|---|
| 顺序或独立模块 | 各模块依次讲完；双栏仅用于双方完整容纳的一页 | 按模块改为顺序逻辑页，标题指出具体主题 |
| 同维度比较 | 双栏或比较表，双方使用相同维度和顺序 | 按维度组拆页，每页仍同时呈现双方；标题指出比较维度 |
| 长步骤或解释 | 前提、步骤及对应结果保持关联 | 在自然子主题处分段，给每页明确目标和承接关系 |

不能仅凭左右各有一个小标题就认定是比较。比如“安装要求/工艺检查”通常是顺序模块；“GCS/GGD的安装结构与检修方式”是比较。判断依靠正文意义，不能只靠标题关键词。

## 容量处理

1. 先去掉重复、套话与备课旁白，保留事实、条件、关键解释、安全要求与结论。
2. 模板已支持弹性参数时，只在其可读范围内调整，并用同一参数测量和发射。当前固定正文模板不允许作者自行改变字号、框高、坐标或行距，不得声称能自动弹性调整。
3. 仍放不下时调整源稿：独立模块各自完整成页；比较按维度成对分组。禁止把一个比较对象全部放前页、另一个全部放后页。
4. 确实需要多页的长模块按子主题均衡分配，不采用前页塞满、后页留下最后一两条的方式。每页要有独立可讲清的问题或结论；不要机械按条数切割，不删内容凑页数。

示例：一次元件占一栏后还剩PT一条，二次元件已在另一栏讲完，应改成“一次回路元件”“二次控制元件”两个完整页面。GCS/GGD比较超长，应拆成“结构与功能对比”“操作与检修对比”，每页均保留GCS和GGD。

## 渲染后的交付门槛

必须重新打开实际生成的 PPTX，提取或查看物理页标题、框内正文和页序；可用 logical→physical mapping 辅助定位，不能只检查 Markdown。逐页连读并检查：

- 是否讲完一个独立模块才出现下一个，避免第一页右侧已经讲新模块、下一页左侧又接旧模块。
- 小标题、解释与其必要条件是否在同一语义段中；是否有仅含残余一两句话且没有独立讲述目标的续页。
- 每张比较页是否仍包含所有比较对象、使用同一组维度；一侧确实不适用时明确说明，不把内容溢出造成的空栏误当成“不适用”。
- 同标题连续页是否重复、跳步或隐藏续文。重复标题和少量条目是复查线索，不是机械失败判据；经合理拆分的独立短页可以保留。
- 调整前后的关键事实、任务与安全要求是否保留，图片和表格是否仍对应各页主题。

任何一项不满足，返回源稿重划逻辑页或布局，重新 validate/render，并对新的实际产物复查。若渲染能力限制使之无法修复，报告具体受影响页与限制，不能标为最终可上课版本。语义检查可以通过程序读取正文辅助完成；不得把该检查冒称 PowerPoint/WPS 人工视觉验收。
