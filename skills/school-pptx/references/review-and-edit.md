# 编辑与验收

## 现有文稿

先保存副本。局部修改直接编辑现有 slide／shape，不经默认新建器重建整份。人工认可的页面按用户范围保留；修复某页页脚遮挡就调整那页内容区域，不能顺便重做已接受页面。改变文字时尽量保留原有分段、字号、加粗、链接、备注和动画；复杂对象无法安全保留时明确说明。

### Visual-only restyle

当用户要求“只改视觉效果”“内容不能删减”或“完整复刻旧 PPT”时，进入内容锁定模式：以旧 PPTX 为底稿，不把内容提取成摘要，不重排页序，不合并或拆分页面，不改写或压缩文字。生成前后必须逐页核对页数、页序、所有非空文字串、图片关系、表格、图表和备注；只允许修改背景、主题、字体、色彩、装饰、页脚、边框、间距和裁剪等视觉属性。若视觉层可能遮挡原对象，应先调整安全区或把视觉对象放到背景层；不能用删除原内容解决冲突。

内容锁定模式的最小验收是：`source_pages == output_pages`、逐页非空文字清单完全相等，且原始 PPTX 字节不被覆盖。仅有视觉差异时，报告自动校验结果；不要把压缩重制稿标成完整重制稿。

## 三层检查

1. **结构与内容**：文件可重新打开，页数、顺序、文字、备注、图片、表格和图表存在；无输入提示／临时占位。检查关系目标与图片可解码。默认学校模板的母版、布局、主题与媒体必须完整保留。
2. **渲染视觉**：把全部页面渲染为 PDF／PNG。先看联系表检查整体节奏，再看长标题、密集文字、时间轴、照片裁剪、表格、章节与封面大图。正文不能进入学校页脚。检查对比度、对齐、换行、人物和文字裁切。修改后重渲染对应页。
3. **实际查看器**：有 PowerPoint／WPS 时检查打开无修复提示、放映、编辑文字／图表、字体替换、备注和多媒体行为。没有实际打开就明确写“渲染与结构检查通过，未做 PowerPoint／WPS 实机验证”。

几何检查只覆盖新建器命名为 `school:*` 的内容对象；嵌套组以组外框为主，文字容量估计不等于真实排版。旋转原版装饰的边界框、文字与背景的合理叠放不是错误。自动 PASS 不能代替看图。

## 发现问题后的处理

文字拥挤先压缩或拆分；关键事实不能为了版面消失。标题优先改短或明确换行；不要在同排内容中随意用不同字号。图片先改裁剪和构图；页脚冲突先上移／缩小内容区域，保留官方页脚。

缺字方框或异常换行时检查预览运行时的字体。不要把渲染器缺字误判为原稿内容缺失，也不要把方框预览交付为已通过。预览工具支持 `--font-dir` 加载现有本地字体，不自动下载字体。

## 交付

最终 PPTX 存入 `exports/`，检查报告和中间渲染存入 `validation/`。按用户需要附 PDF、联系表、源稿与生成脚本，不让原始材料和中间稿混进最终文件列表。重复制作使用新文件名或版本目录，避免覆盖人工改稿。
