# 设计与制作

## 从材料形成故事

先判断是汇报（结论、进展、证据、问题与下一步）、教学（任务、认知、操作、练习与评价）还是答辩（问题、方案、验证与价值）。这些是思考提示，不是强制目录。把事实来源与解释性讲解区分开。参考单位的成果不能改写为本校成果；没有来源的数字不要补齐。

页面计划可以是一张表：页码、标题、核心信息、依据、视觉组织。不要先选布局再把材料倒进去。保留有意义的原图；不需要每页都有照片，也不要为了“有图”添加无关装饰。

## 内容决定构图

| 信息关系 | 可以尝试 | 判断重点 |
|---|---|---|
| 一件有说服力的事 | 大照片＋短结论＋证据说明 | 主体清楚、图与话互相支持 |
| 多项可核验成果 | 大数字＋对应标签／来源 | 数据口径和单位清楚，不捏造增长 |
| 前后差异／两个方案 | 对齐的比较列或前后图片 | 比较维度相同、视觉权重平衡 |
| 路径／步骤／闭环 | 原生节点、箭头和短动作词 | 顺序、方向、反馈关系一眼可见 |
| 阶段性建设 | 时间轴，必要时上下交替 | 节点与日期对齐，文字不穿线 |
| 教学演示 | 设备大图＋定位标注＋操作要点 | 标注指向真实部位，先后动作明确 |
| 多张活动证据 | 统一本体积的照片组＋短说明 | 清楚展示差异，不反复套相同卡片 |

连续页面保持节奏。可以复用网格与字号，但不要把每页都做成四个圆角卡片。证据强的页面应把证据放大；简单结论页可以留白。

## 设计规范的最小内容

记录模板来源与摘要、画布、固定视觉元素、字体、颜色、标题和正文安全区、主要构图原则及照片处理。典型页在真实模板上验证之后，按同一规则扩展全稿。设计规范服务制作，不要求长篇写作或逐字段确认。

## 工具路线

默认使用随技能提供的 `SchoolDeck` 从学校原型页克隆，或直接编辑用户 PPTX。图表、复杂关系图和新组合可用原生 `python-pptx` API；辅助模块暴露实际 slide 对象，不把设计限制到少数预设。

需要额外软件能力时可选择环境内已有工具；保留可维护的项目源文件。采用其他工具也需复用真实学校视觉资产，并验证文字、图表和形状的可编辑性。默认无动画；用户需要时再添加并在真实查看器验证。未经验证的动画、视频播放或字体嵌入不能宣称已完成。
