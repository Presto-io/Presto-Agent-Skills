# 学校视觉规范

默认学校为西安技师学院／西电机电学院。画布13⅓×7½英寸，16:9。保持模板中的实际学校校徽、双校名、绿蓝渐变、书页线、校训和页脚，不凭印象重画。

| 页族 | 视觉规则 |
|---|---|
| 封面 | 主标题居中60pt，副标题居中20pt；学校绿到学校蓝渐变，左上标识，右下校训，底部书页线。 |
| 目录 | 左侧目录／CONTENTS，右侧条目32pt、整体垂直居中；每项前有学校蓝矩形与白色序号；保持校徽和渐变背景。 |
| 章节 | 66pt标题左下对齐，校徽与渐变背景。 |
| 正文 | 48pt顶部标题，两端对齐，y=1.912英寸处保留模板分割线；白底正文与学校页脚。 |
| 结束 | 固定学校尾页，保持校训、渐变、书页线和校徽。 |

正文区x≈0.8–12.5、y=2.15–6.10英寸；页脚从y=6.36开始。正文通常20–28pt，关键数字可40–60pt。拥挤时重组、精简重复或拆页，不能任意缩小已固定的页族标题。标题过长时先改短或明确换行；需要更多空间时调整标题框并下移分割线及正文，确保正文与页脚不重叠，保留固定字号。

文字分组、表格、比较、流程、时间轴和照片组合根据内容设计。顺序讲述保持顺序，比较使用一致维度；不用复杂背景干扰正文。照片和图表保全关键内容，装饰裁剪不得裁掉人脸、校牌、题字或坐标信息。
