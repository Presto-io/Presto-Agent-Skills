# 理论命题契约

## 蓝图

记录职业标准知识点、适用等级、知识域权重、认知层次、题型、题数、分值和预计时间。方案优先于模板，不固定题量或合格线。蓝图的数量与分值必须与最终卷逐项一致。

## 单题质量

- 单选仅一个正确答案；多选明确可选数量规则和计分办法；判断题避免多命题捆绑和歧义否定；简答/计算题给出评分要点、分值与可接受等价答案。
- 题干包含解题所需条件、单位和假设；选项同一维度、干扰项合理，不依赖长度、语法或绝对词暗示答案。
- 解析与答案同源核查，公式、结果和单位复算。不能编造标准条款、设备参数或教材页码；来源不足就近标记待复核。
- 题库引用保留稳定 ID 和授权来源；新编题记录依据及改编关系。随机打乱选项时同步更新答案，禁止只换顺序不改答案键。
- 以内容相似性检查重复，而非只看题目 ID。等值多套匹配知识域、分值、难度、时间和题型，不仅匹配总分。

## 考生与评阅文件

审阅 Markdown 可以包含答案；考生卷只含应公开的题干/选项/答题区。答案卷包含题目 ID、显示题号、正确答案、解析及逐点评分。检查正文、表格、页眉页脚、文本框、批注、修订、隐藏文本和可见字段，防止答案泄露。需删除评阅信息时生成考生候选副本，不覆盖审阅稿。

每题与选项尽量同页，长题合理续页；保留母版密封线等图形。不得因版面紧张删题干、简答评分点或单位。字体缺失渲染不可当中文排版通过。
