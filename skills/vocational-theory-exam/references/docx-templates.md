# 理论 DOCX 模板

`templates/theory-paper-template.docx` 为考生卷；`templates/theory-answer-template.docx` 为答案评分文件。两者从用户实操母版的页面设置、密封线、身份栏、字体及标题框架派生，用占位符替代题目。它们是新增配套模板，尚未经用户理论卷人工审阅，不能称为用户批准的理论母版。

复制对应模板填充全部 `{{…}}` 占位内容；按实际题型扩展题目和选项，不固定四选项，也不固定题量。题目采用真实编号，避免模板文字编号与自动编号重复；答案卷独立使用题号映射。不得使用实操评分表代替理论卷结构。

模板保留母版 package 部件；隐藏未使用的关系资源可能仍含源样例，正式考生交付前按答案隔离契约检查整个 package，并移除明确不再引用的源样例/评阅部件。不要删除被密封线或身份栏引用的绘图。

`scripts/build_templates.py --source <母版.docx> --output-dir <新目录>` 用 Python 标准库重建模板，拒绝覆盖已有目标；它是维护命令，不是正式出卷器。模板安装不需要原始 WeChat 路径，也不需要再次运行维护命令。
