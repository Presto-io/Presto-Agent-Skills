# 内容复核

本报告要为专业设置提供依据：区域和服务企业需要什么人才，现有供给哪里不足，为什么适合本培养层次，以及本校能否并准备如何培养。认可范例用于理解论证方式，不是可直接复制的事实库；历史修订说明与本次要求不一致时，按本次用户要求执行。

## 分章检查

- **调研背景**：产业与技术变化落到本地区、目标岗位和学校服务面向。举办关系、政策介绍只提供背景，不能单独推出人才短缺或开设专业的必要性。
- **目的、对象及方式**：说明要解决的专业设置问题、实际调查对象和资料取得方式。走访、招聘信息、公开统计、同类院校及专家意见各自支持什么判断应清楚；只写实际完成且有材料支持的方法，不能把拟开展写成已开展。
- **调研结果分析**：以需求和供给为主体。结合已有证据分析需求变化、培养层次、岗位类别与关键能力，以及供给总量、结构或技能适配短板。数据范围不支持的细分类不硬补；没有定量资料时如实作有依据的定性分析，不能凭趋势推算缺口人数。
- **调研结论**：先回应必要性和本校办学可行性，再概述培养目标、培养模式、课程体系及专业特色。师资、实训与校企合作对应前文的培养要求；既有条件与拟建设内容分开。详细课程学时、学期进程、设备清单及证明材料放在申报包相应章节，不挤占需求分析。

## 段落与整稿检查

以连贯的正式分析段落呈现判断、依据、解释及其对专业设置的意义，按论证需要组织，不要求每段机械套同一句式。不要用证据清单、技术名词堆叠、图表标题或“符合发展需要”等套话替代分析。

检查专业名称、培养层次、产业与地域范围、岗位口径是否前后一致，不能将研发岗位的需求直接等同于一线技能人才需求。引用的数据要区分实际与预计、人数与岗位数、招聘样本与总体需求；比例、合计及增长计算与来源口径对应。

图表逐一说明支持的正文判断，不能以图数多作为质量证据。图内不放标题和备注，必要说明移到图注或正常正文；禁止为模仿参考稿造样本、造比例或声称完成并不存在的企业调查。

未确定的问题集中在对话或来源资料的待核事项中说明；阻塞关键结论时交付审阅稿，不将缺口隐藏成已核验的正式结论，也不擅自把内部核查说明写进正式报告。

内容复核由 agent 根据实际材料完成，并说明未能确认的范围。DOCX 审计脚本只检查有限格式，不能自动判断需求分析是否充分、调研是否真实或专业是否获批。
