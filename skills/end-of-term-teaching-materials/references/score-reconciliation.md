# 成绩纠错与缺失分项反推

本规则在整理原件、定稿 Markdown 之前执行。纠错与反推由 agent 完成，renderer 只接收确定后的成绩及已确定计分方案，不依赖 renderer 猜测原件或补零。保持既有四件套交付边界。

## 计算错误：两次独立核算

1. 主 agent 主动逐行检查分项合计、加权平均、扣分、封顶及舍入。发现总评分歧时，先回看原件，核对学生学号、任务、分项数值、正负号及计分规则，再用十进制精确计算；不得只凭总分低或高认定错误。
2. 调用独立子 agent，把原件页面/清晰裁图、学生与任务定位、已确定计分规则交给它。要求独立从原件识读分项并计算，返回识读值、表达式、合计、原总评及字迹确定性。不要先给主 agent 的识读值、期望答案或修正结论；子 agent 不直接改最终成绩。
3. 比对两次的学生与任务、全部分项、正负号、公式、封顶/舍入及结果。仅总和相同而分项不同，不算一致。原件清楚、规则明确，且两次完全一致、均与原总评不同，认定原始数据存在计算错误，直接把主成绩表改为正确值，无须教师逐条批准。
4. 若两次不一致、任何一方认为字迹模糊、总分疑似改写、特殊加减分或封顶规则不明确，回看原件后仍不能解决的，向用户实时提问。把当前已知疑点一次编号汇总，不等到最终交付，也不要逐条往返。子 agent 不可用时不得声称已独立复核，未解决的分歧集中交用户判断。
5. 用户明确确认过的分数或例外规则优先；不要覆盖已确认值。可指出新的冲突并集中询问。加分后超过100但原表按100封顶等，只有规则明确时才直接采用，不能把合理封顶当成算术错误。

把两份独立识读/核算记录及修改前后值存放在任务工作目录，包含学生、任务、原总评、正确表达式和修正值。自动纠错后重算全部受影响统计、PDF、Excel；对应 `## 复核标记` 清除。证据不平铺到交付根，也不写入最终四件套的备注、脚注、分析或额外说明章节。

## 前三类成绩缺失：保持总成绩反推补列

范围是记分册的考勤、作业、期末测试三类成绩（Markdown `考勤`、`作业`、`期末`，常用第1、2、3栏）。`期末` 测试列与任务平均得到的 `期末分` 是不同概念，不能相互替换。先确认模板映射，不能把任意表格的前三个物理列、学生身份列或前三项任务当成本规则范围。

老师已把这些项目融入总成绩但未拆列时，AI 应自行补齐，避免仅因这三列缺失而反复询问。遵守以下次序：

1. 锁定已确定的总成绩、其含义和计分方案。分清原表总评是任务总分、过程考核综合分、平时分还是学期总分。只有某个任务的总分，不能直接冒充整门课程总成绩。有既有最终结果时逐人保存为不变目标；已有用户确认方案优先于技能默认公式。
2. 已记录/已确认的三类分项及任务成绩不变，只补缺失项。不得为便于反推而挪动已知分数、重复计入职业素养/考勤、编造一次考试或作业原始记录。没有独立考试但需补第3栏时，补的是符合总分约束的记分册数值，不能在分析中宣称进行过考试。
3. 按已确定公式求解缺失项。若目标为学期总成绩 `S`、过程考核分 `F`，公式为 `S=0.4P+0.6F`，先求所需平时分 `P=(S-0.6F)/0.4`，再反推三类分项。若目标已是平时分，直接以其为 `P`；不要再套学期公式。若本课程约定直接以过程考核综合分作为总成绩且三类均已融入其中，使用该综合分作补列基准，维持原来的总分口径，不另加权一次。
4. 用实际公式系数求解。默认三项公式为 `P=0.3A+0.4H+0.3E`（考勤A、作业H、测试E）；本次明确无独立测试的方案可能是 `P=0.5A+0.5H` 或直接 `P=H`，必须保持既定方案，不能因填上E就自动切换公式。若 renderer 按E是否为空自动分支，应在任务工作副本适配已确定公式和展示值，再复算验证，不改已确定总分迁就默认分支。
5. 多解时采用简单、稳定的等值补列：已知部分对目标的贡献为 `K`，缺失项参与计分的权重和为 `W`，所有缺失计分项取同一值 `x=(P-K)/W`。三项全缺且权重和为1时三项均取P。某缺失栏不参与本次公式时，按P同值补展示，权重仍为0。等值仅是补列约定，不声称是唯一恢复的历史分项。
6. 分数按学校满分范围（通常0—100）及既定精度、舍入核验。使用十进制精确计算，维持缺失计分项等值；优先使用可行的整数，多个整数均可保持目标时选择离精确解x最近的值，距离相同按既定舍入规则选择，未指定则四舍五入。整数不可行时使用模板支持的小数。将反推值代回实际 renderer 的完整公式，核对显示后的平时、期末、学期结果；涉及整数舍入时以最终显示总成绩不变为准，可在满足该目标的舍入区间内取可行解。
7. 目标或公式含义不明、保留已知分数后无满分范围内的解、或模板精度无法维持已定总分时，列入当前集中问题实时询问。禁止简单截断到0/100、覆盖已知值或悄悄变更总成绩。其他任务成绩缺失不适用本自动反推规则，保留空白或按用户另行授权处理。

工作目录保留原空白状态、目标值、公式及反推值，逐人比较补列前后的最终总成绩。定稿 Markdown 主成绩表和打印表格使用确定的补列数值，不附“反推”“估算”“补记”标识，不生成不存在的考勤流水、试卷分项或作业等级明细。若必须适配 renderer，应在任务工作副本完成并检查 workbook 和 PDF 同源一致。

## 交付回复（生成报告）

“生成报告”指最终向用户的交付回复，不增加第五个交付文件。必须在回复中披露：

- 发现并纠正哪些原始计算错误：逐项写学生/任务、原总评、核算正确值；可用紧凑表格。无错误则不虚报。
- 补齐了哪些成绩列，以及“这些列的数据根据已确定的最终总成绩反推，最终总成绩保持不变”。有已知分项时说明只补缺失项。

以上处理说明只出现在交付回复及非交付核算证据中；最终 Markdown、Typst、PDF、Excel 不出现纠错或反推说明，成绩分析仍只写成绩分布、教学问题和改进措施。不要为纯算术纠错和可行反推补列另设确认环节。
