# Cover Template Notes

这些封面说明是技能本地固定模板资源。真实学校模板、桌面文件、私有路径、教师签字图片或学生原始成绩不得写入本目录。

## 成绩记分册

`成绩记分册` 包含重新设计的封面和记分册正文。封面按学校参考样张使用大号居中标题和充分留白，内容依次展示学年学期、班级、学科、授课教师和日期；正文沿用 Markdown 中的学生顺序，显示 `考勤`、`作业`、`期末` 测试列及派生成绩，不直接显示 `任务1..任务N`。

## 教学日志封面

所有封面的信息栏必须按该封面最长字段统一确定宽度：科目、班级、教师、授课教师等每条信息栏的文字区及下划线等宽、起止位置对齐，整组居中。课程名称或其他字段超长时保持原字号，整组信息栏一起弹性加宽，不得只拉长课程栏；安全区容纳不下时增加字段高度并换行，后续字段相应下移。禁止通过缩小字号解决溢出。

教学日志封面使用参考样张的三行下划线信息栏，展示科目、班级和教师；下划线与文字的距离必须和 `成绩记分册` 封面信息栏一致。没有来源字段时不猜测历史周次或日志页码。

## 过程考核评价表封面

过程考核评价表封面使用参考样张的三行下划线信息栏，展示科目、班级和教师；下划线与文字的距离必须和 `成绩记分册` 封面信息栏一致。任务名称和课时仍来自 `## 过程考核任务`，但不在封面上展开。

## 交接班记录封面

交接班记录封面只展示当前班级/教师和交接班级/教师两行，虚线必须位于上下两行信息的中间位置。它需要 `handover_class_name` 和 `handover_teachers`。两个字段任意一个缺失时，必须回到 Markdown 复核和修正，不能生成看似完整的最终交付。

## Review Boundary

任何封面都不得绕过 Markdown 复核规则。只要 `## 复核标记` 不是精确的 `无`，最终 PDF/workbook export readiness 必须失败。

## 封面班级格式

所有封面的班级使用顿号连接，优先保持一行、水平居中；超长时按本页统一弹性信息栏规则加宽，安全区不足才换行，禁止缩小字号。正文专业/班级名称的一行一个、框内左对齐规则不适用于封面。

## 封面教师范围

成绩记分册使用 `teachers` 全部教师；教学日志、过程考核评价表使用单独确认的 `cover_teachers`，未提供时兼容沿用 `teachers`。用户要求只显示本人时确认姓名后写入该字段，不删除其他成绩材料中的任课教师。
