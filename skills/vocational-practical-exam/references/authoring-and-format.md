# 实操命题与 DOCX 版式契约

## 命题

- 以用户提供或明确允许检索的适用职业标准、认定方案及考核条件为依据；记录标准名称、版本、来源和适用等级。不能拿模板标题证明适用性。
- 建立“工作任务 → 能力点 → 可观察操作 → 评分项 → 分值”覆盖矩阵，区分必考、抽选和可选。题数、满分及权重按实际方案确定，不固定为五题或百分制。
- 每题包含情境、任务、设备材料、完成条件、时间、考核要求、评价依据。评分动作能观察，扣分可操作，同一行为不重复扣分；明确单项最低分、累计规则、安全否决与其授权依据。
- 校核各题分值和总成绩计算；多套卷覆盖、难度、时间和设备负荷可比，避免只更换名称而实质重复。

## 逐字重构

- 内容来自每套原卷；从指定母版副本开始，不能直接在原卷上套样式。
- 持久 Markdown 记录完整内容与原文件映射；原 DOCX 中复杂合并、绘图和自动编号仍以保留原件及映射核对，禁止用有损 Markdown 往返掩盖字符丢失。
- 全部文字节点按顺序精确比较，空格、标点、数字、单位均算字符。节点分割变化时还须比对拼接字符序列及段落/单元格边界，不能仅比较字符总数。图形、文本框、页眉页脚另行检查。
- 编号属于显示层：源含文字编号时不能再叠加自动编号；转换为自动编号须用户允许相应源字符迁移，核对显示顺序、重启点、左缩进和悬挂缩进。
- 加粗按母版语义角色映射；标题、考核时间/要求与普通正文区分，不把整题描述或列表默认加粗。

## 表格与分页

- 总成绩表以及每道题评分表的标题在新页起始；第一道评分题紧接总成绩表后的分页点。题数动态，不固定六个分页点。使用有效分页符或 `pageBreakBefore`，`w:val="0"` 不算启用。
- 表格外正文空行与段落结构保持不变，不能为评分表清理而全文删空行。
- 表格宽度按所在节版心计算，`tblW`、`tblGrid` 与各 `tcW`（含合并跨度）一致；表格缩进也计入可用宽度。窄数字列、较宽叙述列按文字量平衡。关闭自动拉宽，取消会截断内容的固定行高，保留动态行数与合并结构，跨页重复表头。
- “序号”“考核内容”列水平和垂直居中；“合计”段落清除首行、悬挂及字符单位缩进，设零缩进。考核要点、评分标准等叙述列按批准母版设置。
- 只清理评分区表格单元格中的多余空段、文字后尾随手动换行和连续空行；有意义的多段评分规则与语义换行保留。空单元格至少保留一个必需段落，保留合并占位。分页型 `w:br` 和列分隔不得当普通换行删除。
- 删除空段前检查图片、域、书签、批注锚点和控件，不能因无 `w:t` 就当空白。清理前后所有非空文字和表格外 XML 内容核对一致。

## 经验参数的适用边界

本次风电中级五题母版曾采用评分表宽 8170 twips、表格缩进 120 twips、考核要求左缩进 840 twips/悬挂 420 twips；这仅是该模板的已验证参数。新职业、新页边距、新母版必须重新测量，不能机械套用。模板密封线、侧边框、文本框和页眉页脚是必须核对的页面元素。
