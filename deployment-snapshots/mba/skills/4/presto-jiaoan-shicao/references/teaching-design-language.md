# 教学设计方案语言与内容生成参考

本参考来自两份 160H 职业教育课程教学设计方案的结构与措辞归纳：

- `高压电器装配与调试`
- `电气设备控制线路安装与调试`

生成 `jiaoan-shicao` 实操教案时，除非用户明确要求其他风格，优先采用本参考的表达方式。

## 总体写作特征

样本文档的文本不是说明文，也不是教学反思，而是面向课堂实施的过程性安排。每一句都要服务于“学生做什么、教师怎么组织、用什么方法、产出什么结果”。

核心风格：

- 任务情境具体：常用企业订单、班组接收任务、设备安装维修、现场勘察、查阅资料、制定计划、领取工具材料、安装调试、验收评价等场景。
- 目标表达可观察：多用“能够……”“能……”“掌握……”“了解……”“理解……”。
- 内容表达动作化：多用“查阅、识别、检测、绘制、安装、接线、调试、排查、填写、展示、评价、整改”等动词。
- 教学流程职业化：按工作过程展开，不只按知识点展开。
- 句式简洁密集：表格单元格通常由短句、分号和编号组成，避免长篇议论。
- 安全和规范贯穿：经常写入安全用电、劳动防护用品、6S 管理、工位整理、操作规程、质量标准。

## 推荐教学过程结构

输入材料不完整时，优先补全为职业教育实操课常见的六段式过程。可根据课时和主题删减，但顺序尽量保持工作过程逻辑。

1. 获取信息
   - 安技教育、旧知回顾、明确任务、下发任务书、查阅资料、新知讲授。
2. 制定计划
   - 解读任务要求、梳理工作流程、制定实施计划、准备工具材料。
3. 做出决策
   - 小组汇报计划、比较方案、确定实施路线、明确分工和评价标准。
4. 实施计划
   - 识别与检测元器件或零部件、绘制图纸、安装装配、接线调试、记录数据。
5. 检查控制
   - 自检互检、功能测试、故障排查、质量验收、整改完善。
6. 总结评价
   - 成果展示、小组自评互评、教师点评、填写任务单或评价表、归纳经验。

## 学习任务描述写法

如果要从主题补写任务背景，优先写成“真实工作任务”而不是抽象课程介绍。

常用结构：

```text
某企业/生产现场接到一项……任务，要求在规定时间内完成……。学生以工作小组形式从班组长处接收任务，通过阅读任务单、查阅设备说明书和技术资料，明确工作内容、工期、质量、安全等要求；根据任务要求制定实施计划，准备工具、材料和仪器仪表，按操作规程完成……，经检查、调试和验收后形成工作记录，并进行总结评价。
```

高压电器装配类可写：

```text
学习……设备的结构原理，掌握……零部件识别、质量检查、装配调整和调试验收操作，能够按工艺要求完成设备装配与功能检查。
```

电气控制线路类可写：

```text
某机床/设备生产企业接到安装与维修任务，要求电气安装班组根据任务单和设备资料，完成控制线路原理分析、元器件识别检测、线路安装接线、通电调试、故障排查和验收记录。
```

## 学习目标写法

目标通常分为知识目标、技能目标、素养目标。即使用户只给了主题，也要补出三类目标。

知识目标常用句式：

- 了解……的结构组成及各部件功能。
- 掌握……型号含义、主要技术参数和工作原理。
- 理解……动作过程、控制逻辑或工艺要求。
- 掌握……质量标准、检测方法和安全操作规程。

技能目标常用句式：

- 能够正确识别……零部件/电气元件，并完成质量检查。
- 能够正确使用……工具、仪器仪表和检测设备。
- 能够按图纸、工艺文件或任务书完成……安装、装配、接线或调试。
- 能够对……常见故障进行分析、排查和处理。
- 能够填写任务单、检测记录、验收申请单等工作文件。

素养目标常用句式：

- 培养安全文明生产意识和规范操作习惯。
- 培养小组协作、沟通表达和计划执行能力。
- 培养质量意识、责任意识和精益求精的工匠精神。
- 形成整理工位、规范摆放工具、遵守 6S 管理要求的职业习惯。

## 学习内容写法

学习内容要区分“学什么”和“做什么”，优先用知识内容、技能内容、职业素养内容组织。

知识内容示例：

- ……整体结构及工作原理。
- ……型号含义及主要技术参数。
- ……电气原理图、接线图、布局图识读。
- ……装配工艺要求、质量标准和检测方法。
- ……安全操作规程、现场管理规范和 6S 管理要求。

技能内容示例：

- 任务书解读与工作计划制定。
- 元器件/零部件识别、检测与选用。
- 工具、量具和仪器仪表的正确使用。
- 图纸绘制、线路安装、设备装配、通电调试。
- 常见故障排查、质量验收和记录填写。

## 教学活动表写法

`学习内容` 列写“本环节教什么、训练什么”。  
`学生活动` 列写学生的具体行为，避免只写“学习”“听讲”。  
`教师活动` 列写教师如何组织、示范、提问、指导、评价。  
`教学方法与手段` 列写短语，不写成长段。

### 学习内容常用表达

- 检查学生仪容仪表，强调课堂纪律和安全注意事项。
- 回顾……的功能、符号、接线方式和检测方法。
- 解读……工作任务单，明确工作内容、工期、质量和安全要求。
- 查阅……设备说明书、原理图、接线图和技术资料。
- 梳理……工作流程，制定任务实施计划。
- 识别并检测……元器件/零部件，记录检测结果。
- 按图纸完成……安装、接线、装配或调试。
- 完成自检互检，排查并整改存在问题。
- 完成成果展示、任务验收和学习评价。

### 学生活动常用表达

- 检查工作服、绝缘鞋、绝缘手套等穿戴情况，并按要求整改。
- 接收任务书，阅读任务要求，明确施工内容和验收标准。
- 以小组为单位查阅资料，讨论并记录关键技术要求。
- 识读电气原理图、装配图或工艺文件，完成工作页填写。
- 制定工作计划并进行展示汇报，根据意见修订完善。
- 按分工领取工具、材料和仪器仪表，完成工位布置。
- 按操作规程完成安装、装配、接线、检测和调试。
- 进行自检、互检和故障排查，填写检测记录。
- 观摩其他小组成果，开展自评、互评并分享学习体会。

### 教师活动常用表达

- 清点学生出勤，检查劳保用品穿戴和工位安全情况。
- 创设工作情境，下发任务书，说明任务要求和评价标准。
- 引导学生查阅资料，讲解设备结构、工作原理和操作要点。
- 示范工具、仪器仪表和关键工序的规范操作方法。
- 组织学生分组，指导学生制定工作计划并进行展示汇报。
- 巡回指导学生实施任务，纠正不规范操作，提示安全风险。
- 检查学生安装、装配或调试结果，指导学生整改问题。
- 组织成果展示、自评互评和过程评价，进行总结点评。

### 教学方法与手段常用短语

- 讲授法、提问法、演示法、任务驱动法。
- 小组讨论法、展示汇报法、角色扮演法。
- 现场教学法、巡回指导法、讲练结合法。
- 案例分析法、工作页引导法、线上线下混合教学。
- 微视频观看、实物展示、正向激励法、总结归纳法。

## 课时分配规律

如果用户未给课时，可按活动粒度估算：

- 安技教育、明确任务、总结评价：通常 0.5H-1H。
- 旧知回顾、资料查阅、新知讲授、计划制定：通常 1H-2H。
- 展示汇报、方案决策、工具材料准备：通常 1H-2H。
- 安装、装配、接线、调试、故障排查：通常 2H-6H，可拆多行。
- 过程考核、验收整改：通常 1H-2H。

总课时明确时，应让各活动课时之和尽量贴近总课时；总课时不明确时，优先生成完整但不过度冗长的 6H-12H 教学活动设计。

## 根据输入完整度补全

### 输入是完整教案或表格

保留原有任务、环节、活动、课时和师生活动，只修正为模板所需标题层级。语言可轻度润色，但不要改变教学意图。

### 输入是课程名称或学习任务

围绕主题生成一套完整教学活动设计。默认包含：任务导入、安全教育、资料查阅、计划制定、实施操作、检查调试、总结评价。

### 输入是零散知识点

先判断知识点属于认知、操作、检测、调试还是评价，再把它们嵌入工作过程。例如“接触器、热继电器、正反转控制”应组织为“元器件识别检测 → 原理图识读 → 线路安装 → 通电调试 → 故障排查”。

### 输入是非职业教育文本

提取可教学化的主题和任务，把它转成“学习某项技能/完成某项作品/解决某个现场问题”的实操课。不要照抄原文堆满表格。

## 质量检查清单

生成前后检查：

- 是否有 `template: "jiaoan-shicao"`。
- 是否只使用 `##`、`###`、`####`、`#####` 表达教案表结构。
- 每个 `#####` 后是否有四个内容块。
- 学生活动是否写成学生行为，教师活动是否写成组织指导行为。
- 教学方法与手段是否为短语。
- 是否体现安全、规范、质量、评价和 6S 管理。
- 是否避免空泛句，如“学生认真学习”“教师讲解相关内容”。
- 是否避免生成 `.typ`、`.docx`、临时转换文本等中间产物。
