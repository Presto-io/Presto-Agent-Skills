# 52-01：受控媒体与原生视觉对象

1. 为四种 frozen visual layout 实现 manifest-geometry 驱动的原生对象发射；每个冻结 object role 必须映射到非空的 shape/text/picture 集合。
2. 图片只消费已验证的 `MediaBinding.payload`，保持 contain，拒绝 hash/format/size 漂移与路径二次读取。
3. 对 caption、KPI、annotation/leader、process node/connector、footnote 使用原生可编辑对象，不生成整页 bitmap。
4. 扩展固定验证，重开 PPTX 检查形状类型、文本、媒体关系、可移动/可取消组合所需的非图片信息层和拒绝截图。
