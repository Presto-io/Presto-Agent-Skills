# 51-03：发射器消费边界与阶段验证

## 目标

使 renderer 只将完整冻结计划交给 emitter，并以 fail-closed 边界证明 emitter 不会重新决定视觉或分页。

## 任务

1. 在 `pptx_render.py` 连接 parse -> VisualPlan -> PhysicalDeckPlan -> emit 的唯一管线；公开/诊断 projection 使用冻结数据。
2. 在 `pptx_emit.py` 验证 schema、完整 binding、variant、对象角色、映射和媒体 hash；任一缺失、未知或不匹配均稳定失败。
3. 加入 mutation guards，证明 emitter 不会选择 variant、重新分页、变更裁切/字号、按路径替换媒体或补推导计划字段。
4. 将 Phase 51 固定验证加入既有 renderer verifier，明确其不证明 Phase 52 原生对象或 Phase 53 fixture/UAT。
5. 更新 renderer reference，只记录已实现的冻结边界与可运行验证命令，不提前声明后续阶段通过。

## 验证

`python3 skills/school-pptx/scripts/verify_pptx_renderer.py`

`python3 skills/school-pptx/scripts/verify_school_pptx.py`（仅在既有完整回归仍可运行时执行）

## 完成标准

emitter 只能机械消费同哈希的完整计划；所有布局选择、分页和媒体绑定均在发射前可复算并被冻结。
