# 51-01：冻结视觉输入与投影模型

## 目标

在现有 immutable `PhysicalDeckPlan` 基线上，增加由已审阅文档、manifest、template 和单次读取媒体绑定的 immutable `VisualPlan`，并使扩展后的物理页投影包含 schema、variant、对象角色、媒体身份和连续映射。

## 任务

1. 在 `pptx_model.py` 定义 frozen、slots 数据类和 canonical JSON/SHA-256 projection。字段必须覆盖 51-CONTEXT D-01--D-04，且序列顺序不可依赖 dict 遍历。
2. 在 `markdown_contract.py` 暴露规划所需的受限视觉语义、源行和媒体引用；不得重新解析 Markdown 或引入作者几何/样式字段。
3. 在 `pptx_paginate.py` 以 held descriptor 的单次读取结果构建媒体 binding，并将 manifest/template/Markdown 哈希写入计划。缺失、格式非法、过界或哈希不符必须保留稳定非零诊断，不能在后续按路径重新读。
4. 为 serialization、冻结性、键排序、输入哈希与媒体 TOCTOU 建立单元级固定回归。

## 验证

`python3 -m py_compile skills/school-pptx/scripts/pptx_model.py skills/school-pptx/scripts/markdown_contract.py skills/school-pptx/scripts/pptx_paginate.py`

新增验证入口必须对同一 fixture 两次产生 byte-identical canonical projection，并对 manifest/template/Markdown/媒体任一变化拒绝或变更绑定。

## 完成标准

未发射 PPTX 前即可获得唯一、不可变、可复算的视觉投影；路径本身不能充当媒体身份。
