# 51-02：确定性 variant、原子组与物理映射

## 目标

把四种新 layout 及 image-text/gallery 的 manifest 预设机械映射为稳定 variant 和物理页；所有分页在 emitter 前完成。

## 任务

1. 从 manifest 的固定 preset 和受限语义派生唯一 variant：hero 2/3 KPI、annotated-image 3/4/5 anchors、process 2--6 steps、KPI 2/3/4 cards、媒体页 1--4 items。作者不得指定 variant。
2. 将媒体+图注、KPI 卡、标注编号+标签+锚区+引线、流程节点+连接关系表示为不可拆 atomic group。
3. 按 D-06 的最少页数与最早连续前缀字典序规则分页，冻结 `physical_index`、continuation、完整有序 `logical_to_physical`、容量和对象角色。
4. 空页无法表达的组或不连续分区须以稳定、定位的 diagnostics 失败，禁止缩字、裁切、静默丢失、临时换 layout。
5. 扩展 renderer verifier，固定覆盖每种 variant、跨页、边界容量、超量失败、输入顺序与重复运行确定性。

## 验证

`python3 skills/school-pptx/scripts/verify_pptx_renderer.py`

验证必须从原始 fixture 重算 projection，不接受生产者常量或动态跳过。

## 完成标准

每张物理页都可反向追溯到 Markdown 源行、manifest variant 和已绑定媒体，且重复运行映射完全一致。
